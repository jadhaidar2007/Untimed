# Untimed
Untimed is a tiny, private Mac app that hides the menu-bar clock so you can focus without watching the minutes pass. Hide or reveal the time with one click, start a quiet focus session, or take a five-second peek when needed. No accounts, no tracking, and no Accessibility permissions—just your time, without the time.
The first public release of Untimed—a tiny Mac app that hides the menu-bar clock so you can focus without watching time pass.

Features:
- Hide or reveal the clock with one click
- 15, 25, and 45-minute focus sessions
- Five-second clock peek
- No accounts, tracking, or Accessibility permissions

Requirements:
- Apple Silicon Mac
- macOS 14 or newer

Because this beta isn’t notarized yet, macOS may block the first launch. Open System Settings → Privacy & Security → Open Anyway.
